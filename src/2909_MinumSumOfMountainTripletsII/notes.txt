Learned of transducers from "janetacar".

(i think her last name is just a reference to lisp)

I would explain transducers as, chaining filters
maps reducers but without creating intermediate data structures.

xs
|> filter p
|> map f
|> reduce r

Creates two intermediate data structures that we only
use to feed to the next function.

Not only do we avoid creating intermediate data structures,
we also do the entire thing in one pass.
We filter, map, reduce all in one pass.
